# 🚀 Advanced Physical Design using OpenLANE / Sky130

Welcome to a 5-day immersive physical design program using the OpenLANE RTL-to-GDS flow and the SkyWater SKY130 PDK.
This series combines foundational concepts, SoC design methodology, and practical hands-on labs using fully open-source EDA tools.

## 📅 Day 1 – Inception of Open-Source EDA, OpenLANE & SKY130 PDK
Introduction to the open-source silicon ecosystem and the fundamentals of modern SoC design flows.
You will explore how computers interpret hardware instructions and how OpenLANE leverages open-source infrastructure.

Focus

- 🌐 Evolution of open-source EDA + PDKs
- 💻 How computers interpret instructions (binary → logic → circuits)
- 🧩 Introduction to SoC design methodology
- 🔧 OpenLANE flow structure and tools
- 🛠️ Getting familiar with Yosys, OpenROAD, Magic, KLayout
- 📁 Understanding SKY130 PDK contents

## 📅 Day 2 – Floorplanning & Standard Cell Libraries
Explore what makes a good floorplan, how placement works, and how standard cells are designed and characterized.

Focus

- 🧱 Good vs bad floorplan characteristics
- 🏗️ Chip floor-planning considerations (pin/IO planning, congestion, area)
- 🔗 Library binding and placement flow
- 🧬 Standard cell design and characterization basics
- ⏱️ General timing characterization parameters

## 📅 Day 3 – Library Cell Design & CMOS Fabrication Insight
Hands-on creation and characterization of a library cell. Includes layout design using Magic, SPICE simulation, and understanding fabrication concepts.

Focus

- ✏️ Designing a library cell layout using Magic
- 🔍 Ngspice characterization of a CMOS inverter
- 🧪 Insight into CMOS fabrication steps
- 📘 SKY130 technology files: layers, rules, device models
- 🧯 DRC, extraction, and parameter verification

## 📅 Day 4 – Timing Analysis & Clock Tree Synthesis
Understand timing behavior before and after CTS, model delays, and implement a real clock network using TritonCTS.

Focus -
- ⏳ Pre-layout timing analysis
- 📊 Delay modeling using lookup tables
- ⚙️ STA using OpenSTA (ideal vs real clocks)
- 🌲 Clock Tree Synthesis using TritonCTS
- 🔕 Signal integrity, skew, and buffering
- 🧭 Timing analysis after CTS

## 📅 Day 5 – RTL-to-GDSII Completion & Routing
Finish the physical design flow with routing, DRC cleanup, PDN generation, and final GDS export.

Focus -
- 🛣️ Routing fundamentals + TritonRoute workflow
- 🚨 Design Rule Check (DRC) and fixes
- 🔌 Power Distribution Network (PDN) generation
- 🚀 TritonRoute features and optimizations
